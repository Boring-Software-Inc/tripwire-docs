You need a Tripwire account and permission to install the Tripwire GitHub App on the repository.

1. Sign in to the [Tripwire dashboard](https://app.tripwire.sh).
2. Follow the setup checklist to install the GitHub App. Grant it access to the repository you want to protect.
3. Select the repository in Tripwire. Open **Rules** to see which checks are installed, then open **Workflows** to review when those checks run.
4. Open a pull request from an account outside the repository's maintainers. In Tripwire, open **Activity** and select the run to see the outcome.

Use a test repository if you want to see how a block or review affects a pull request before applying the workflow to an active project.

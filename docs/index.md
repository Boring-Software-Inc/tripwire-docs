Tripwire evaluates pull requests against rules you set. It can pass a contribution, block it, or hold it for human review. Each run records the checks and their results.

Start by [connecting a GitHub repository](/quickstart). To manage workflows in code, [install the CLI](/cli) and [write a TypeScript workflow](/typescript-sdk).

| Task | Guide |
| --- | --- |
| Decide what runs when a pull request opens | [Workflows](/workflows) |
| Check a contributor or change request | [Rules](/rules) |
| Decide a held contribution | [Human review](/human-review) |

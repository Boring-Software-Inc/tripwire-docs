Tripwire checks contributions when events such as opening a pull request trigger a workflow. The workflow can block the contribution or pause for a maintainer. Open Activity to see what ran and why.

## How a check works

1. A trigger starts a workflow, for example when someone opens a pull request.
2. A [rule](/rules) checks something about the contribution, such as how many files it changes.
3. The [workflow](/workflows) uses the result to decide what to do. If it pauses, a maintainer can decide in [Human review](/human-review).

Open the run from **Activity** to see which rules passed, which failed, and what Tripwire did.

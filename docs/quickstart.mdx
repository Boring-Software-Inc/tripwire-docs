Open your repository in a coding agent and paste this prompt.

<Prompt description="Help me set up Tripwire for this repo" actions={["copy"]}>

Help me set up Tripwire for this repo.

Identify the repository from its Git remote. If the Tripwire MCP server is available, use its setup skill. Otherwise, help me install it with `npx @tripwire-sh/cli install` and sign in from my coding agent. If I need to approve browser sign-in or connect the GitHub App, give me the link and wait.

Check which rules the repository already uses. Suggest a short starting set based on the repo. Ask before saving rules or turning on the gate. After setup, show me where to find the repository’s Activity.

</Prompt>

<Callout type="info">
  You’ll finish sign-in and approve the **GitHub App** in your browser when prompted. [Agent sign-in guide](/agent-auth).
</Callout>

## Set up in the dashboard

Connect your GitHub repository in [Tripwire](https://app.tripwire.sh). In **Rules**, install the checks you want and set their thresholds. Turn on the **gate** to apply them.

## View activity

As contributions come in, open **Activity** for your repository. Select a run to see the checks Tripwire evaluated and the actions it took.

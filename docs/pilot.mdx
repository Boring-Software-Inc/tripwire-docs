title: Pilot
description: A public list of GitHub accounts reported for spam and reviewed by maintainers.
---

**Pilot** publishes account listings with a reason and an optional expiry. You can read the list or contribute a report through the [Pilot repository](https://github.com/Boring-Software-Inc/Pilot).

## Suggest or appeal a listing

Open an issue in the repository. Include the GitHub username or profile URL and explain what you want added, corrected, or removed. Link to public examples when reporting an account.

<Callout type="info" title="Public reports">
  Keep private evidence out of GitHub issues.
</Callout>

## Review matches in Tripwire

On eligible GitHub repositories, open **Rules**, then **Library**, and install **Pilot**. Tripwire sends pull requests from listed accounts to **Human review** for a maintainer to approve or block.

## Read the list from a tool

The [published JSON snapshot](https://raw.githubusercontent.com/Boring-Software-Inc/Pilot/published/snapshot.json) includes each listing’s GitHub username, reason, and expiry. An empty expiry means the listing has no scheduled end.

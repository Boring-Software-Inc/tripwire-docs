## Report or appeal a listing

Include the GitHub username or profile URL and explain what you want added, corrected, or removed. For a report, link to public examples such as pull requests or comments.

<Callout type="info">
  Keep private evidence out of GitHub issues.
</Callout>

## Review matches in Tripwire

**Pilot** is available in the **Rules Library** on eligible GitHub repositories. When a listed account opens a pull request, Tripwire matches the author’s GitHub account ID against the active list.

<Callout type="info" title="Example">
  A listed account opens pull request #42. The pull request stays open and appears in **Human review**. A maintainer can inspect the run for the match and choose **Approve** or **Block**.
</Callout>

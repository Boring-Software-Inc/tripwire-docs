## Find out why a pull request is waiting

Open Human review for your repository. Each waiting item shows the pull request, its author, and the reason it was held. Select the item to inspect the run before deciding.

<Frame caption="Each item shows its reason for waiting next to the author and time.">
  ![Human review queue with waiting pull requests and Block and Approve buttons on each item.](/screenshots/human-review.png)
</Frame>

## Approve or block

Choose Approve to continue the workflow, or Block to block the contribution. After deciding, open the run from Activity to see the recorded outcome.

---
title: Human review
description: Hold a pull request for a maintainer decision before the workflow continues.
---

Add **Human review** to a workflow when a check should inform a decision that a maintainer makes. For example, send changes to a sensitive path for review while letting other pull requests follow the usual workflow. Tripwire pauses the run when it reaches this action and adds the pull request to the repository’s review queue.

## Decide a waiting item

Open **Human review** for the repository. Select a pull request to inspect the run and see what triggered the pause.

| Decision | What happens |
| --- | --- |
| **Approve** | Resumes the run on the approval branch. |
| **Block** | Blocks the pull request and follows the denial branch if the workflow defines one. |

Open the run in **Activity** to see the recorded decision and subsequent actions. [Configure workflow branches](/workflows).
